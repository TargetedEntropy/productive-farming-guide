# Surface brief: index.html (the whole guide)

Scope: single-page guide. Visitor mode: Read.

Audience and job: ATM11 players with the game open beside them, looking up one fact (a cross, a trade level, a structure rule) or reading once top to bottom. Content: overview, crop forms, traits, crossbreeding, auto-farm, animals, flowers and dye, searchable crop index, searchable recipe finder, power-player points, known issues, credits. Constraints: static GitHub Pages, no mod textures (mod is All Rights Reserved), credits with links are mandatory.

Decision path: the owner asked for an uninterrupted publish, so no decision round was held. The dice assigned candidate 7 of 7 from the grounded list (seed catalogue, botanical field guide, extension bulletin, genetics textbook, crate-label lithography, Isotype pictorial statistics, transit network diagram). Code-led: no image generation on this machine.

Memorable moment: the crop mutation tree drawn as a transit network map you can ride station by station.

## Direction contract

THESIS: Productive Farming is a network, so the guide is a network map. Mutation chains are lines, crops are stations, and the page is wayfinding around them. It refuses the fan-wiki arrangement of dirt-texture banners, pixel fonts and a wall of item icons, and it refuses the dark neon gamer dashboard.

OWN-WORLD: Transit diagram and signage standards. Flat white map paper by day, navy night-map ground after dark. A locked set of saturated line colours plus ink; no tints, no gradients, no shadows. Thick round-capped route lines, ringed station dots, double-ring interchanges, square stops for non-mod inputs, numbered line roundels. One signage grotesque derived from highway lettering, with its mono companion for codes and numbers.

STORY: The reader learns what the mod adds, sees every cross on one map, then drops into the section that answers the question. They leave knowing which seed to buy, what to cross, and how to build the farm.

FIRST VIEWPORT: Slim signage bar across the top: PF roundel, guide title, version plate, contents, theme switch. Below, left-aligned title at display scale with a two-sentence opening and three way-forward links (look up a crop, find a recipe, power-player points). Under it, starting inside the first viewport and running full content width, Figure 1: the crossbreeding network map, six coloured lines, with a platform board directly under it showing the selected station's recipe and an odds calculator (the board moved below so the map can run full width and stay legible). On desktop a sticky left rail lists the twelve sections as stations on one vertical line.

FORM: transit network diagram and wayfinding signage; position 7 of 7 on the grounded list; seed key 032870ef. Raises taken from the declined hand: locked palette with no in-between tones (PC-98 field); drawn lengths equal real quantities, so chance bars are to scale (Labanotation); a strict lettered bullet for every section and numbered steps only where order matters (orizuru sequence); one consistent gotcha mark for bugs and book corrections (hand-drawn zine); state carried by mark as well as hue: ring style for buyable versus mutation-only, tick count for villager level (cutting-bench rail).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
